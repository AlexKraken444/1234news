# 1234 NEWS

Сайт новостей класса на Next.js, готовый к развёртыванию на Vercel. Публичная страница показывает статьи и видео, а защищённая страница `/admin` позволяет их публиковать.

## Развёртывание на Vercel

1. Импортируйте этот GitHub-репозиторий в Vercel.
2. В проекте Vercel откройте **Storage**, создайте **Blob Store** и подключите его к проекту. Переменная `BLOB_READ_WRITE_TOKEN` добавится автоматически.
3. В **Settings → Environment Variables** добавьте:
   - `ADMIN_PASSWORD` — необязательно; задайте его, только если хотите заменить стандартный пароль администратора
   - `SESSION_SECRET` — необязательно; при отсутствии для подписи сессий безопасно используется закрытый токен Blob Store
4. Запустите Deploy. После этого публикации доступны по адресу `/admin`.

## Локальный запуск

Скопируйте `.env.example` в `.env.local`, заполните переменные и выполните:

```bash
npm install
npm run dev
```

Без подключённого Blob Store главная страница работает и показывает пустое состояние, но публикация материалов недоступна.
